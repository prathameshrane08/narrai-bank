# NarrAI web app

The white-label banking web app (Next.js). See the [project README](../README.md) for setup, and
[Deploying the web app on Vercel](../README.md#deploying-the-web-app-on-vercel) for hosting.

```bash
npm install
npm run dev        # http://localhost:3000 (needs the API on :8000 and frontend/.env.local)
npm run lint
npm run build
```
